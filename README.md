# Лендинг кофейни «Тёплый угол» (демо)

Демо-проект для портфолио: одностраничный сайт для кофейни. Кофейня вымышленная.

**Демо:** https://leonti123.github.io/landing-coffee/

## Что внутри
- Адаптивная вёрстка (ПК, планшет, телефон), мобильное меню
- Меню с переключением категорий
- Галерея, блок отзывов, карта
- Форма бронирования: маска телефона, валидация, выбор даты и времени
- Анимации появления блоков при прокрутке
- Чистый HTML/CSS/JS, без сборки и фреймворков, один файл

## Запуск
Открыть `index.html` в браузере.
