# Сайт кофейни «Утро на Фонтанке» (концепт)

Одностраничный сайт для кофейни в Санкт-Петербурге с онлайн-предзаказом навынос. Кофейня придумана для портфолио.

**Сайт:** https://leonti123.github.io/landing-coffee/

## Что внутри
- Меню с фото, выбором объёма и корзиной
- Предзаказ: время самовывоза по часам работы, заказ уходит готовым текстом в WhatsApp или ВК
- Статус «открыто / закрыто» по московскому времени
- Бронь столика с выбором даты и свободного времени
- Карта гостя (каждый 7-й кофе в подарок), блок обжарки, галерея, пример блока отзывов
- Контакты: карта, WhatsApp, ВК (в ВК текст заказа копируется в буфер, так как ВК не умеет подставлять сообщение)
- Адаптив: на телефоне корзина открывается снизу
- Чистый HTML/CSS/JS, один файл, без сборки

## Запуск
Открыть `index.html` в браузере.
